Buy the photobooth kit

We sell the complete photobooth kit of a Minute Papillons « solo » (unattended) booth. Everything you need to run the booth yourself : computing, lighting, payment, shooting and printing.

What’s in the kit

Five blocks, all wired and documented (reference: the Suzon booth) :

  • Computing — Raspberry Pi 4 (4 GB), microSD card, OS and Python kiosk (dedicated venv).
  • Front panel — 8×8 LED matrix (MAX7219, SPI), 7-segment display (TM1637), NeoPixel strip.
  • Payment — coin receiver (GPIO input), START button, AI/classic selector, and optionally an MDB cashless card reader.
  • Camera — Canon EOS 1500D connected in USB PTP (reflex mode, gphoto2 driver).
  • Printer — DNP DS-RX1 (CUPS, gutenprint53 driver).

A few exact references (coin receiver model, NeoPixel strip, power supplies) are still to be completed — we will specify them in your quote.

And with the kit, you receive

  • The PDF manual — Part I : the photobooth kit, Part II : the booth hardware (frame, venue electricity, on-site operations).
  • The ZIP of resources — STL files, configuration files, wiring diagrams in SVG.
